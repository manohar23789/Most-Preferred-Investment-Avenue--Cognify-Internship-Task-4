## Task 4: Most Preferred Investment Avenue

### Objective
Identify the most preferred investment avenue in the dataset.

### Description - This task analyzes the `Investment_Avenues` column to determine which investment avenue has the highest frequency.

### Analysis Performed
- Loaded the dataset using Pandas
- Examined the `Investment_Avenues` column
- Calculated the frequency of each investment avenue
- Identified the most preferred investment avenue
- Calculated the percentage of preference
- Created a bar chart to visualize the investment preferences

### Technologies Used
- Python
- Pandas
- Matplotlib
